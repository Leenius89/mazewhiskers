# 클로드 인수인계: 메이즈 위스커스 앱인토스 등급분류

2026-09-25 작성. 이 문서는 다음 작업을 맡을 클로드에게 그대로 전달할 수 있는 작업 요청서다.

## 목표와 현재 상태

메이즈 위스커스를 토스 앱의 미니앱(앱인토스)으로 정식 출시하려 한다. 사업자등록은 완료했고, 게임물제작업자등록증도 이전 인수인계상 발급 완료 상태다. 게임 개발 시작 연도는 사용자 확인 기준 2024년이다. **사업자 공동인증서 발급 완료**를 사용자가 2026-09-25 다시 확인했다. 인증서 파일·비밀번호는 이 문서나 대화에 기록하지 않는다.

마지막으로 확인된 GRAC 업체회원 상태는 **미가입(2026-09-22)**이다. 이후 가입했는지는 아직 확인하지 않았다. 기존 GRAC 문의도 2026-09-22 기준 회신 대기였으며, 이후 회신 여부는 확인하지 않았다. GRAC 신청·납부·자료 업로드는 아직 수행했다는 증거가 없다.

실제 심사 준비 저장소는 `F:\JoongminLee\12_프로젝트_Project\Game\MazeWhiskers\mazewhiskers-toss`이다. 현재 Codex 작업 폴더인 `F:\JoongminLee\Project\Game\MazeWhiskers`와 **다른 경로**이므로, 먼저 실제 저장소를 확인하라. 기존 자료의 주장보다 사용자 최신 답변, 현행 GRAC 화면·회신, 실제 게임 구현을 우선한다.

## 지금 이어서 할 일

1. **GRAC 업체회원 가입을 진행한다.** [GRAC](https://www.grac.or.kr/)의 현행 업체회원 가입 화면에서 사업자등록증·게임물제작업자등록증의 상호, 대표자, 사업자번호 표기를 대조한다. 발급받은 사업자 공동인증서가 해당 로그인/전자서명에 지원되는 종류인지 실제 화면으로 확인한다. 사용자만 인증서 선택·비밀번호 입력을 수행하면 된다. 가입 후 승인 필요 여부와 상태를 기록한다. 이미 가입한 상태라면 중복 가입하지 말고 로그인과 업체정보를 확인한다.
2. **기존 GRAC 문의 회신을 확인한다.** 특히 앱인토스 오픈마켓 간소화 경로, 실행 ZIP과 URL 중 허용 방식, 토스 전용 기능을 보여줄 영상, 동영상 형식·분량, 수수료·중소기업 감면 절차, 출시 후 수정 신고 기준을 확인한다. 회신이 없다면 [확인 질문 초안](review-20260922/GRAC-확인질문-초안.md)에서 답이 필요한 항목을 현행 접수 화면과 대조해 문의한다. 수수료 금액·감면율·영상 최소 분량을 이전 문서의 추정치로 확정하지 않는다.
3. **제출 버전을 확정한다.** 9월 22일 검토본의 게임 소스는 `c7533e4e7e2f3d32a31ef4e9a4544ac3aa1bfe9f`이고 실행 ZIP은 `store-assets/grac/실행파일_메이즈위스커스_web_20260922_c7533e4.zip`이다. 9월 25일 확인한 `HEAD=5eeafe5`(9월 27일에 `3e19a17` 검토 자료와 `62053f8` 음원 라이선스 문서로 나뉘어 이 해시는 더 이상 없음)는 GRAC 준비자료·스크립트만 추가했고 게임 소스 변경은 확인되지 않았다. 그래도 접수 직전 최신 `git diff`와 실제 토스 `.ait` 빌드의 동일성을 다시 확인한다. production에서도 `?mode=arcade` 경로가 있으므로 출시 포함 여부를 결정하고, 포함한다면 설명서·영상·실행 안내에 유지한다.
4. **실제 토스판 증거를 완성한다.** 기존 [영상 촬영 개정안](review-20260922/영상-촬영-개정안.md)에 따라 앱인토스 QR 실기기에서 일반 진행, 추격·피해·게임 오버, 광고(전면/보상), 순위표, 빙판, 오늘의 도시, 도감, 영어 부적절 문구와 아케이드 경로 등 신청 내용에 해당하는 장면을 검증·녹화한다. 선택형 보상 광고는 다음 판 점프 횟수 +1이고, 인앱 결제·유료 재화·확률형 아이템은 없다는 기존 구현 설명과 실제 출시판을 대조한다. 영상 타임코드를 [신청 입력 초안](review-20260922/신청-입력초안.md)에 채운다. 같은 버전의 화면으로 PDF 삽입 스크린샷도 교체한다. 현재 PDF의 화면은 이전 참고 이미지다.
5. **신청 화면에 맞춰 최종 제출한다.** 토스 [등급분류 안내](https://toss.im/apps-in-toss/blog/game_rating_classification)는 개인사업자의 업체회원 로그인, `등급분류신청 → 오픈마켓/등급분류 신청`, 플랫폼 `모바일 게임`, 스토어 `기타-앱인토스`, 서비스 방식 `인터넷 접속`을 안내한다. 실제 화면의 질문에는 게임의 폭력성·공포 연출·영어 부적절 문구 등 사실을 누락 없이 기재하고, 해당 요소를 영상에 표시한다. 내용설명서, 실행 가능한 게임물, 진행 영상, 제작업자등록증 등 현행 요구 서류를 맞춘다. 신청·납부 전 수수료 및 감면 적용 방법을 확인하고, 접수번호·제출 버전·첨부파일명·납부 내역을 기록한다.
6. **심의 결과를 앱인토스에 반영한다.** 등급분류증명서를 받으면 토스 콘솔의 게임 등급분류 단계에 증명서 PDF를 첨부하고 증명서 기재 내용과 동일하게 입력한다. 토스 심사·출시 및 이후 업데이트 시 등급 관련 변경신고 필요 여부는 그때의 GRAC 안내로 확인한다.

## 첫 응답에서 사용자에게 알려줄 것

인증서 발급 다음 단계는 **GRAC 업체회원 가입과 인증서 호환 확인**이다. 가입이 이미 끝났다면 로그인·승인 상태부터 확인하면 된다. 이어서 GRAC 회신, 최종 게임 영상·제출 형식, 수수료를 확인하고 신청한다. 비밀번호나 인증서 파일을 보내 달라고 요청하지 말고, 사용자가 본인 기기에서 인증하도록 안내한다. 접수 준비와 자료 교정은 가능한 범위에서 계속 진행한다.
