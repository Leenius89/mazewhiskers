# 메이즈 위스커스 등급분류 준비 현황

2026-09-22 기준. 대상은 `mazewhiskers-toss`의 `toss` 브랜치, 게임 소스 `c7533e4e7e2f3d32a31ef4e9a4544ac3aa1bfe9f`, 표시 버전 0.1.0입니다. 아직 GRAC에 신청하거나 파일을 전송하지 않았습니다.

## 현재 판단

내용 교정본, 실행본, 문구 대조표, 촬영안, 신청 입력 초안을 준비했습니다. **접수 가능한 최종 제출 묶음은 아직 아닙니다.** 업체회원 가입, GRAC 회신, 실제 토스판 영상, 출시 범위 확인을 완료한 뒤 최종본으로 확정해야 합니다.

기존 DOCX에는 오늘의 도시·빙판·도감·광고가 이미 반영되어 있었습니다. 이번 검토에서는 이 기능의 단순 누락보다 **규칙 설명의 오류, 이전 실행 ZIP, 추가 실행 경로 누락**이 주요 문제였습니다.

## 검증 결과

- production 웹 빌드 성공: 시뮬레이터 비활성, 소스맵 제외, 기존 빌드 폴더와 구분하여 `build-grac` 사용.
- 기존 관련 테스트 3개 스위트, 74개 테스트 통과: `cityPlan`, `cityKinds`, `mazeGrid`.
- 빌드에는 기존 `bendSound` 미사용 경고와 Browserslist 데이터 갱신 안내가 있음. 이번 작업에서 게임 코드나 의존성을 변경하지 않음.
- ZIP CRC 및 웹 파일 68개 SHA-256 일치 확인. 실행 안내·글꼴 라이선스·manifest를 별도 동봉.
- 브라우저 기본 메뉴·설정·오늘의 도시 진입 및 게임 화면 확인. `?mode=arcade`에서 `구역 1/3` 표시도 확인. 토스 SDK 광고·진동·랭킹 및 모든 엔딩을 실기기에서 검증한 결과는 아님.
- 교정 PDF 11쪽을 이미지로 렌더링해 모든 페이지의 한글·표·이미지·줄바꿈을 확인. 잘못된 회복 조건·추격 설명·글리치 제한 문구와 미기입 개발 연도가 남지 않았는지 텍스트로도 검사.
- 원본 DOCX 자동 렌더링은 번들에 LibreOffice가 없어 실패. 원본 DOCX는 수정하지 않고, 내용 교정 Markdown과 직접 생성한 PDF로 제공.

## 접수 전 남은 일

1. GRAC 업체회원 가입·승인을 완료하고 보유 인증서가 지원되는지 확인.
2. 기존 문의의 회신으로 실행본 제출 방식, 영상 형식·분량, 감면 조건·시점, 업데이트 절차를 확정.
3. 실제 출시 진입 주소와 아케이드 경로의 포함 여부를 확정. 현재 자료는 포함된 코드의 사실을 설명하며 임의 삭제하지 않음.
4. 같은 소스의 토스 `.ait` 빌드 식별값을 기록하고 QR로 실기기 검증·녹화. 이번 작업에서는 태그 push나 토스 업로드를 수행하지 않음.
5. 같은 버전으로 스크린샷 교체. 교정 PDF의 삽입 화면은 기존 DOCX의 참고 이미지임을 명시함.
6. 실제 영상 타임코드로 신청 입력 초안의 증거 위치를 채움.
7. 원제·게임물명·콘솔 표시명·상호를 실제 증빙과 대조. 수수료 감면 관련 답을 확인한 뒤 신청·납부.

## 공식 근거와 확인 범위
