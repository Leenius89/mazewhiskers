# 심사 영상 촬영 개정안

2026-09-22 / 소스 c7533e4. 기존 촬영안의 등급 관련 장면은 유지하고 최신 기능과 실제 종료 연출을 추가했습니다. **30분·MP4 허용 여부는 확정되지 않았습니다.** 먼저 필요한 장면을 확보하고 GRAC 회신에 맞춰 분량·컨테이너·해상도·편집 방식을 정합니다.

## 촬영 준비

- 토스 QR에서 실행한 실제 토스판을 우선 사용합니다. 토스 빌드 ID·소스 커밋·앱 버전·날짜·언어·난이도를 기록합니다.
- 브라우저 보조 영상은 환경을 자막이나 파일명으로 구분합니다. 가짜 광고나 개발용 강제 상태를 실제 광고 보상 증거로 사용하지 않습니다.
- 소리를 포함해 녹화합니다. 공포 요소의 강도는 무음 영상만으로 설명하지 않습니다.
- ‘화면 효과 줄이기’와 기기 동작 줄이기를 모두 확인합니다. 기본 효과와 줄인 효과를 구분하여 녹화합니다.
- 튜토리얼 재현에는 `?tutorial=1`을 사용할 수 있습니다. 시뮬레이터의 `?plan=glacier`는 production 실행본에서 무시되므로 같은 방법으로 된다고 안내하지 않습니다.
- 날짜별 도시는 현재 날짜의 실제 종류를 기록합니다. 개발용 강제 도시를 사용하면 보조 검증본임을 표시하고 제출본과 혼동하지 않습니다.

## 제출 전 확인

- 영상과 설명서·실행본의 소스 버전 일치.
- 실제 파일을 처음부터 끝까지 재생해 소리·글자 가독성·검은 화면·잘림 확인.
- 공식 답변에 맞는 파일 형식, 용량, 분량, 편집 허용 여부 확인.
- 신청서에는 최종 파일의 실측 타임코드만 입력.
- 현재 로컬 브라우저 화면 확인은 위 제출 영상의 제작 완료를 뜻하지 않습니다.
