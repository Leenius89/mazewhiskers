# GRAC 확인 질문 초안

미발송 문안입니다. 기존 문의가 회신 대기 중이므로 먼저 회신을 대조하고, 답이 빠진 항목만 추가 문의에 사용합니다. 신청자 이메일·사업자번호·인증서 정보는 이 문서에 넣지 않습니다.

제목 제안: 앱인토스 HTML5 게임 등급분류 제출 방식 및 신청 준비 확인

안녕하세요. 개인사업자로서 토스 앱 내 미니앱 형태의 HTML5 게임 ‘메이즈 위스커스’를 출시하려고 합니다. 무료 이용 게임이며 전면 광고와 선택형 보상 광고가 있고, 인앱 결제·유료 재화·확률형 아이템·환전·이용자 간 거래는 없습니다. 보상형 광고는 다음 판의 점프 횟수를 1회 추가합니다.

기존 문의에 대한 답변과 함께 아래 사항을 확인 부탁드립니다.

1. 모바일 게임 / 기타 앱인토스의 오픈마켓 간소화 신청 경로로 진행할 수 있는지, 이 경로에서 요구하는 서류와 실행 자료의 정확한 목록을 알려주실 수 있을까요?
2. 토스 전용 .ait 번들은 토스 앱에서만 실행됩니다. 같은 소스의 브라우저 실행 ZIP과 실행 안내를 제출해도 되는지, 아니면 접속 URL이 필요한지 확인 부탁드립니다. URL이 필요하면 접근 제한·계정·제공 기간 조건도 부탁드립니다. 브라우저에서 작동하지 않는 토스 광고·순위표·진동은 토스 앱 영상으로 입증해도 되는지 궁금합니다.
3. 실행 영상에 MP4(H.264/AAC)를 사용할 수 있는지, 최소 또는 권장 분량·해상도·용량·장면별 편집 허용 여부를 알려주실 수 있을까요? 일반 신청과 간소화 신청의 기준이 다른지도 확인 부탁드립니다.
4. 개인사업자의 중소기업 수수료 감면 자격, 제출 증빙, 사전 지정 절차 및 신청·납부 전후의 적용 시점을 확인 부탁드립니다. 광고 수익이 있는 무료 게임이며, 비영리 개인 게임 면제로 신청하려는 것은 아닙니다.
5. 업체회원 가입 시 사용할 수 있는 사업자 공동인증서 종류·용도를 확인 부탁드립니다. 카카오뱅크 발급 사업자 공동인증서를 보유하고 있으나 해당 인증서의 호환 여부를 확인하려 합니다. 비밀번호나 인증서 파일 전송 없이 종류·용도 정보만으로 확인할 수 있는지도 부탁드립니다.
6. 출시 후 문구·난이도·광고 보상·도시 종류·실행 모드가 변경되는 경우, 내용수정신고와 재분류 판단에 적용되는 현행 안내 및 처리 절차를 알려주실 수 있을까요?

감사합니다.
